# AkiDuermo Android Play preparation

Package ID: `com.akipasa.duermo`. Launch URL: https://akiduermo.com/. This is a standalone native shell and unsigned CI bundle; it is not proof the accommodation web extraction is finished.

**Important:** This repository's main README documents migration groundwork only. Production login, hotel search, bookings and tenant isolation need independent verification before any store submission.

Release blockers: Android App Links with the Play **app-signing** certificate, real-device OAuth return, app listing, data safety, review credentials, approved final brand icon, new independent Play signing setup and upload keystore. Keep keystore and passwords out of GitHub. Do not merge or deploy until tests pass.
