# AkiDuermo Android Play preparation

Package ID: `com.akipasa.duermo`. Launch URL: https://akiduermo.com/. This is a standalone native shell and unsigned CI bundle; it is not proof the accommodation web extraction is finished. Localized Play listing copy and the data-safety engineering inventory live in `store-listing/`; the canonical 512 px store icon is `../public/brand/duermo-icon.png`.

**Important:** This repository's main README documents migration groundwork only. Production login, hotel search, bookings and tenant isolation need independent verification before any store submission.

Release blockers: Android App Links with the Play **app-signing** certificate, real-device OAuth return, final screenshots/feature graphic, Play Console Data Safety/content rating, review credentials, independent Play signing setup and upload keystore. Keep keystore and passwords out of GitHub. Do not submit until tests and production acceptance pass.
